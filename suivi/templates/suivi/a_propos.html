La plateforme

Cette plateforme a été développée pour Saint-Étienne Métropole Tourisme & Congrès afin de centraliser et structurer la collecte des indicateurs de fréquentation des sites touristiques du réseau Loire.

Elle remplace les remontées manuelles (emails, fichiers Excel ad-hoc) par un outil unique, sécurisé et directement connecté aux outils de pilotage existants (Power BI, exports Excel).

Documentation API

L'API JSON permet à des outils externes (Power BI, scripts, tableurs) de récupérer les données sans passer par l'interface web. Elle est accessible en lecture seule via une clé d'authentification.

GET /api/indicateurs/
→ Tous les indicateurs

GET /api/indicateurs/?annee=2026
→ Filtre par année

GET /api/indicateurs/?mois=6&site=3
→ Filtre par mois et par site

GET /api/sites/
→ Liste des sites actifs

Authentification : header X-API-Key: votre_clé ou paramètre URL ?cle=votre_clé. Les clés se génèrent dans Utilisateurs (administrateur uniquement).
